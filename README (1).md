# 🤖 BYTE — AI-Питомец (Тамагочии девелопер)

Веб-сайти интерактивӣ дар шакли Тамагочи бо персонажи **Байт** (AI-бот).
Як файл (`index.html`) — бе вобастагӣ, бе build.

## Асосӣ
- 4 нишондиҳанда: ⚡ Энергия, 💖 Кайфият, 🧪 Сифати код, ☕ Кофе (бо вақт кам мешаванд)
- 4 амал: Кофе/хӯрок, Код нависед, Fix Bugs, Истироҳат/Хоб
- Садоҳо (Web Audio), аниматсияҳои CSS, фони Matrix (Canvas)

## Имкониятҳои иловагӣ
1. ☕ **Coffee Overload** — 3 кофе пайдарпай → Super Developer (чашмони неонӣ, барқ, Bug-ро пешакӣ меёбад)
2. 😴 **Режими хоб** — энергия 0 → Байт худ хоб меравад, Zzz, баъд барқарор мешавад
3. 🐛 **Bug Hunter** — багҳои зинда дар экран, клик → аниматсияи нест шудан + XP
4. 🏆 **Level** — XP, ҳар Level ранг ва қобилияти нав
5. 🧠 **Эҳсосот** — хурсанд, оддӣ, хаста, ғамгин, ҳайрон, асабӣ, хоболуд
6. 🎁 **Тӯҳфаи махфӣ** — ҳар 5 амали хуб → қуттӣ бо мукофот
7. 📅 **Миссияҳои ҳаррӯза** — ҳар рӯз 3 миссияи нав
8. 🪙 **Танга ва мағоза** — хӯрок, либос, ранг, эффект
9. 💬 **Чат** — бо Байт сӯҳбат кунед
10. 🌗 **Шабу рӯз** — шаб неон, ситора, хоболудӣ
11. 👕 **Либос** — кепка, тоҷ, айнак, гӯшмонак, ҳуди... (нигоҳ дошта мешавад)
12. 🌌 **Ultra Developer Mode** — энергия/кайфият ≥85, сифат ≥75 + XP

Ҳамаи пешрафт дар `localStorage` захира мешавад.
Тугмаҳо: `Space` код · `C` кофе · `F` fix · `S` хоб.

## Деплой
**GitHub Pages:** push → Settings → Pages → Branch `main` / root.
**Netlify:** папкаро ба netlify.com/drop кашед.
**Vercel:** `vercel` дар папка.
